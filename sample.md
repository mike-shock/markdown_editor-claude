# Markdown Editor Sample

This is a **sample** document for the *Fyne* Markdown editor.

## Features

- Open, edit, preview and save `.md` files
- Export to HTML (sans-serif typography)
- Web View in the system browser
- Synchronous scrolling of editor and preview
